¿Qué es un nodo?

Un nodo (xᵢ, yᵢ) es un dato conocido. Todos los valores de x deben ser distintos. Con n nodos se construye un polinomio de grado como máximo n − 1.

El ejemplo usa memoria (GB) y latencia (ms). Para otros problemas, x e y representan tus variables.

APRENDE MIENTRAS CALCULAS

La teoría detrás de cada resultado.

∏

01 / Construir las bases

Para cada nodo k, se multiplican los factores que comparan x con los otros nodos.

Lₖ(x) = ∏ᵢ≠ₖ (x − xᵢ)/(xₖ − xᵢ)

Los denominadores no pueden ser cero: por eso no se permiten abscisas repetidas.

∑

02 / Interpolar y evaluar

La suma ponderada de las bases produce el único polinomio de grado ≤ n − 1 que pasa por n nodos distintos.

P(x) = ∑ₖ yₖ Lₖ(x)

El cálculo usa dos bucles anidados: su complejidad es O(n²) para cada evaluación.

≈

03 / Entender el alcance

Interpolar estima un valor entre datos conocidos. Extrapolar extiende el polinomio más allá de ellos.

Error = f(x) − P(x)

Sin conocer f o sus derivadas no se obtiene el error real. Muchos nodos pueden causar oscilaciones; aquí se permiten de 2 a 10.
